## 1. 후보 기준

- 나라: 대만·일본(본문 언어 번체 중국어 / 일본어)
- 팔로워: 1천~2만 (Threads 기준. 인스타가 더 크면 메모)
- 니치: 잠금화면·배경화면 배포, 다꾸(手帳·手帳デコ), 스터디(勉強垢·讀書帳), 아이폰 꾸미기(ホーム画面カスタマイズ·桌面佈置)
- 아이폰 사용자일 것(잠금화면 캡처가 iOS)
- 최근 14일 안에 게시물이 있을 것
- 반응: 최근 게시물 10개 좋아요 중앙값 ÷ 팔로워 ≥ 2% (팔로워만 많고 반응 없는 계정 제외)
- 최근 30일 경쟁 앱(LockDay·Catlendar 등) 협찬 글이 있으면 표시만 하고 제외하지는 않는다(협찬을 받아본 계정이라 오히려 빠를 수 있다)
- 제외: 우리 페르소나 계정과 상호작용(팔로우·리포스트)이 잦은 계정, AI 생성 이미지만 올리는 계정, 남의 캐릭터 그림을 배포하는 계정

찾는 검색어: JP `ロック画面` `壁紙配布` `手帳デコ` `勉強垢` `ホーム画面カスタマイズ` `iPhoneカスタマイズ` / TW `鎖定畫面` `桌布` `手帳` `讀書帳` `iPhone 桌面佈置` `桌布分享`

## 4. 브리프 (크리에이터에게 보내는 1장)

**Trace × {크리에이터} — Threads 게시물 1건**

- 목표: 잠금화면에 일정이 뜨는 모습을 크리에이터 본인 잠금화면으로 보여준다.
- 형식: 우리 2장 캐러셀 템플릿 그대로
  - 1장: 본인 잠금화면 캡처(본인 배경 + Trace 위젯/일정). 시계·알림의 개인정보는 가린다
  - 2장: 설정법 한 장(우리가 언어별로 제공 — `images/tut-jp.png`·`images/tut-tw.png` 기반, 1장과 같은 비율로 재편집해 전달)
- 그림: **원화만.** 본인 그림이거나 우리가 주는 Trace 원화 배경. 도라에몽·미피·산리오 등 남의 캐릭터, 다른 작가 그림, 출처 불명 이미지 금지
- 본문: 본인 말투로 1~3줄. 터진 글 뼈대(`items.json` 카피기준)를 참고로 주되 강요하지 않는다. 기능 나열 금지
- 광고 표시: **필수.** 본문 첫 줄에 일본 `#PR`, 대만 `#廣告`(또는 `#業配`). Threads 브랜디드 콘텐츠(유료 파트너십) 표시 기능이 계정에 열려 있으면 같이 켠다
- 링크: 본인 첫 답글에 우리가 준 캠페인 링크(`ct=cr_<jp|tw>_<핸들>`, `research/attribution.md` — pt 받은 뒤 발급)
- 일정: 초안 이미지 사전 확인 1회 → 발행일 협의 → 발행 후 7일 삭제·비공개 금지
- 2차 활용: 공식 계정 리포스트 허용 여부, 광고 부스트 사용 허용 여부·기간을 계약 때 따로 체크(미정 #6)
- 하지 말 것: 우리 페르소나 계정 언급·태그·리포스트, 경쟁 앱 비교 비방, 과장 효능("절대 안 까먹음" 보장 문구)

## 6. 공식 계정 Trace JP·Trace TW

- 역할: 원화 배경화면 배포처 + 크리에이터 게시물의 허브. 페르소나 계정과는 완전히 분리한다.
- 2주 일정(배포 4회): 1주차 화·금, 2주차 화·금. 현지 19시 전후(`items.json` _시각기본값·_시각분산). 회차마다 원화 1종 × 2장(배경 / 설정법) = `items.json` wallpaper-drop 아이템과 같은 구성
- 본문: 공식 계정은 앱 이름을 써도 된다. 첫 줄은 "무료 배경 배포" 한 줄, 링크는 답글(`ct=of_jp`·`of_tw`)
- 리포스트: 크리에이터 협업 게시물은 리포스트한다(허용, 계약서에 명시). **우리 페르소나 계정 글은 절대 리포스트·인용·태그하지 않는다** — 계정끼리 리포스트 금지(스펙 §4)이고, 공식 계정이 페르소나를 밀면 연결이 드러난다
- 댓글: 팀원이 사람 손으로 직접 답한다(스펙 §7). 자동 답장·템플릿 복붙 금지. 배포 글 댓글의 "어떻게 설정해?" 질문은 2장째 설정법으로 안내
- 그림: 원화만. 캐릭터 IP 사용 금지(wallpaper-drop IP 규칙)
- 측정: 배포 글 48시간 조회·저장·리포스트, 답글 링크 ct 설치 수. 대시보드 연결은 계정 등록 후(`/setup`)
