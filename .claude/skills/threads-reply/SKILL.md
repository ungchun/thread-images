# Threads 답글 대응

작업 폴더는 이 레포 루트다. 도구는 `replies.py`.

토큰은 대부분 GitHub Secrets에만 있다. 로컬 `accounts/<계정>/env.sh`가 있는
계정만 직접 실행되고, 나머지는 `replies.yml` 워크플로를 거친다.

## 절차

한 번에 한 건씩. 답장은 되돌릴 수 없으니 발행 전에 반드시 사용자 승인을 받는다.

### 1. 계정 선택

`accounts/*/meta.txt`를 읽어 계정과 국가를 보여주고 사용자가 고른다.
인라인 텍스트로 묻는다. AskUserQuestion 금지.

### 2. 게시물 선택

```bash
python3 replies.py posts <계정> --days 30
```
로컬 토큰이 없으면:
```bash
gh workflow run replies.yml -R ungchun/thread-images \
  -f cmd=posts -f account=<계정> -f arg=30
```
날짜·조회수·하트·댓글수와 첫 줄을 보여주고 사용자가 고른다.

### 3. 미답변 답글 목록

```bash
python3 replies.py list <계정> <게시물id>
```
시간순으로 나온다. 각 답글의 원문과 **한국어 번역**을 함께 보여준다.
사용자는 베트남어·중국어를 읽지 못한다. 번역 없이 원문만 던지지 않는다.

### 4. 톤 파악 (답장 쓰기 전 1회)

```bash
python3 replies.py tone <계정> --limit 20
```
그 계정이 지금까지 쓴 답장이 나온다. **이 톤에 맞춘다.** 새 톤을 만들지 않는다.
`accounts/<계정>/faq.md`가 있으면 함께 읽는다. 반복 질문의 확정 답변이 들어 있다.

### 5. 한 건씩 답장

답글 하나마다 이 순서를 지킨다.

1. 원문 + 한국어 번역을 보여준다
2. **한국어 답장 초안을 제안한다** (사용자가 쓰는 게 아니라 내가 먼저 낸다)
3. 사용자가 승인하면 현지어로 번역
4. 발행하고 결과를 알린다

사용자가 고치라고 하면 초안을 다시 쓴다. 건너뛰라고 하면 다음으로 넘어간다.
**승인 없이 발행하지 않는다.**

발행:
```bash
printf '%s' "<현지어 답장>" > /tmp/reply.txt
python3 replies.py send <계정> <답글id> /tmp/reply.txt
```
본문을 파일로 넘기는 이유는 줄바꿈·이모지가 셸에서 깨지기 때문이다.

로컬 토큰이 없는 계정은 발행도 워크플로를 거쳐야 한다. `replies.yml`에는
아직 send가 없다 — 필요해지면 그때 추가한다(토큰이 Secrets에만 있어서
로컬 발행이 불가능한 계정이 대부분).

## 함정

- **`has_replies`로 미답변을 판정하지 않는다.** 그 필드는 하위 답글 존재 여부라서
  제3자가 대댓글을 달아도 True다. `replies.py`는 conversation 전체를 받아
  우리 계정이 `replied_to`로 가리킨 ID를 빼는 방식으로 판정한다. 이미 구현돼 있다.
- **답글은 페이징이 있다.** 인기 글은 수백 건이라 커서를 끝까지 따라가야 한다.
  `paged()`가 처리한다.
- **GET에 토큰을 본문으로 보내면 190이 난다.** 반드시 쿼리스트링.
- **발행은 컨테이너 생성 → 3초 대기 → publish.** 바로 발행하면 간헐 실패한다.
- 토큰 값을 출력하거나 대화에 붙이지 않는다.
- 답장은 API로 삭제할 수 없다. 잘못 나가면 앱에서 직접 지운다.

## FAQ 축적

같은 질문이 반복되면 `accounts/<계정>/faq.md`에 확정 답변을 적어둔다.
다음 실행부터 초안 품질이 올라간다. 형식은 자유롭게 질문-답변 쌍으로.

베트남 계정에서 실제로 반복된 것: 앱 이름, 무료 여부, 안드로이드 지원,
구글 캘린더 연동, 맥 지원, 잠금화면 설정법.
